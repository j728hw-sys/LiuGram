# LiuGram

LiuGram is an unofficial, noncommercial fork of Vianigram, a Telegram client for Windows Phone 8.1.

The project uses reverse engineering to continue development because the original Vianigram repository was unavailable when this fork was created.

Development combines analysis and targeted modifications of the compiled application, available source backups, and new modules written in C#. This is not a complete rebuild of the original application from source.

LiuGram is maintained independently. It is not an official release by the Vianigram developer, the Vianium project, or Telegram.
